 PilarBus

 Descripción del proyecto
PilarBus es un proyecto académico desarrollado en Python.
Su objetivo es ofrecer una aplicación relacionada con
el transporte y facilitar el acceso a la información.

 Tecnologías utilizadas
- Python
- Git
- GitHub

 Control de versiones
Utilizamos Git y GitHub para almacenar el código,
registrar los cambios y facilitar el trabajo colaborativo.

 Pull Requests
Los integrantes del equipo podrán trabajar en diferentes
ramas del repositorio. Mediante Pull Requests podrán
proponer modificaciones para que sean revisadas antes
de incorporarlas a la rama principal.

 Integración Continua (CI)
Utilizaremos GitHub Actions para ejecutar automáticamente
las validaciones del código cada vez que se realicen cambios.

 Build y Test
Se comprobará que el proyecto pueda ejecutarse y se
realizarán pruebas para detectar posibles errores.

 Entrega Continua (CD)
Una vez superadas las validaciones, el proyecto podrá
prepararse para su publicación o despliegue.

 Lenguaje
Python
